# Best Version of Me

A web-based digital journal prototype for the Best Version of Me youth self-awareness workshop by Global Community Sports.

**Live site:** [https://digital-journal-s1-50.vercel.app/](https://digital-journal-s1-50.vercel.app/)

## Overview

The prototype digitises selected paper journal activities, including skills rating, self-compassion prompts, seeking and giving feedback tools, weekly self-reflection, mindfulness exercises, saved records, and browser-based PDF report export.

The current implementation is frontend-only. Journal entries are stored in the user's browser with `localStorage`, which is suitable for prototype demonstration but not a production data-storage model.

## Technology

- [Next.js](https://nextjs.org/) 15 (App Router)
- React 19 & TypeScript
- Tailwind CSS
- Framer Motion (selected interactions)
